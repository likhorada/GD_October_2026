# Lousy Transformation — итерации разработки

Основано на файле «Октябрь - Финальная версия ГДД.md».

## Текущие договорённости

- Движок: Godot 4.7.2.
- Платформа: Web, хостинг на GitHub Pages через GitHub Actions.
- Первый прототип: один цельный уровень, три события и финал.
- Волосы: кинематические кривые с лёгким визуальным покачиванием.
- Графика: пиксель-арт заглушки.
- UI: русский и английский языки, настройка звука, интро, пауза, победа/поражение.
- Смерть: откат к последнему чекпоинту, жизни восстанавливаются до 3.
- «Выход» в Web-версии ведёт в главное меню.
